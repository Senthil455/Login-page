# Login Page

A modern, responsive sign-in page built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive design with mobile-first breakpoints
- Form validation with real-time feedback
- Password show/hide toggle
- Remember me functionality using localStorage
- Semantic HTML with ARIA attributes for accessibility
- Smooth animations and transitions
- Social login buttons (Google, GitHub)

## Usage

Open `index.html` in any modern browser. No build tools required.

## Structure

```
.
├── index.html    # Main HTML document
├── style.css     # All styles with CSS custom properties
└── script.js     # Client-side form logic
```
